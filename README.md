# Kaliba Proxy Finder

![Kaliba Logo](img/kalibaproxy.jpg)

When your proxy stops working, Kaliba keeps you moving.

## Getting Started

1.  Ensure you have Python installed and the necessary dependencies.
2.  Run `scanner.py` using Python.
3.  Follow the interactive CLI menu to select your scanning preferences and protocol.
4.  Once the scan completes, choose from the available options to save or utilize your working proxies.
